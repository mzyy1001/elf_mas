# ELF-MAS — Coupled Multi-Agent Language Flows

Research project on role-specific specialization in multi-agent diffusion language
models. Two substrates:

- **ELF (JAX/Flax)** — `src/elf_mas/` — the original framework used for Phase 1
  and Phase 2 (MuSiQue-2hop) lesion-matrix experiments.
- **Cola-DLM (PyTorch)** — `src/elf_mas_pt/` — Phase 3 port. Frozen Cola DiT
  (1.8B) backbone + per-agent LoRA injection + token-CE auxiliary loss.

## Status

| Phase | Substrate | Result |
|---|---|---|
| 1 | JAX synth_2fact_v1 | A-only Δa=0.146 vs Δb=0.015 (~10× asymmetry) |
| 2 | JAX MuSiQue-2hop | Per-bucket asymmetry; B0 beats matched single-head |
| 3 | PyTorch Cola+LoRA-MAS | AB-bucket 58.5% per-token EM, Δa=42.7pp, Δb=58.5pp |

Full Phase 3 reproduction recipe (training command + post-mortem on what worked):
`notes/phase3_results.md`.

## Phase 3 quickstart

```bash
# Train Cola+LoRA-MAS on synth_2fact_v1 (~100 min on a single A100)
PYTHONPATH=src python -m elf_mas_pt.training.train_cola \
  --dataset_dir data/synth_2fact_v1 \
  --variant full --batch_size 8 --num_steps 30000 --lr 1e-4 --seed 0 \
  --S_q 16 --S_ctx 64 --log_every 500 --prefix_cond \
  --lora_mode --lora_layers 8,12,16,20 --lora_inner 512 --lora_heads 8 \
  --lambda_ce 0.3 --t_distribution uniform \
  --out_dir runs/cola_mas_pilot/b0_lora_uniform_lce0.3_30k

# Eval with per-token-ID metric (text decode is misleading — see notes)
PYTHONPATH=src python -m elf_mas_pt.eval.eval_cola_mas \
  --ckpt_dir runs/cola_mas_pilot/b0_lora_uniform_lce0.3_30k \
  --dataset_dir data/synth_2fact_v1 \
  --split eval --n_items 200 --batch_size 8 --T_inf 16 \
  --variant full --lora_mode
```
